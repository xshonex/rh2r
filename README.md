# RH2R 发布仓库

本仓库**只存放发布产物**，不包含源代码。

RaiseHandToRecord（RH2R）是一个跨设备灵感速记工具。源码不公开，请勿在本仓库寻找程序代码。

## 下载

在右侧 **Releases** 中按版本下载：

| 文件 | 用途 |
| --- | --- |
| `rh2r-android-v{版本}-arm64-v8a.apk` | Android 安装包（arm64） |
| `rh2r-patch-v{旧版本}-to-v{新版本}-arm64-v8a.patch` | Android 差分更新补丁 |
| `rh2r-models-v{版本}.zip` | 离线语音识别模型（首次启动自动下载） |

## 说明

- 应用内更新会读取本仓库的 Release，请勿删除已有附件。
- Windows 端通过应用内更新分发，不在本仓库。
- 本仓库不含账号、密码、令牌等任何凭据。
